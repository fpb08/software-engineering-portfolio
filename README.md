# Software Engineering Portfolio

A static portfolio website for a college software engineering project. The pages share one CSS stylesheet and use relative links, semantic HTML, and a responsive layout.

## Project files

```text
software-engineering-portfolio/
├── index.html                 # Home page
├── template.html              # Starting point for additional pages (not in navigation)
├── about.html                 # Interests and background
├── projects.html              # Website and AxionMC project summaries
├── skills.html                # Current learning and interests
├── resume.html                # Resume page skeleton
├── contact.html               # Contact page skeleton
├── proposal.html              # Part 1 project proposal
├── css/
│   └── styles.css              # Shared site styles
├── js/
│   └── script.js               # Existing optional JavaScript file
├── planning/
│   ├── wireframes.html         # Part 2 wireframes
│   ├── wireframes.css          # Part 2 wireframe styles
│   └── accessibility-plan.md   # Accessibility planning
└── assets/
    └── diagrams/site-map.svg   # Site map
```

## Preview locally

Open `index.html` in a web browser. The pages use local system font fallbacks so they work without external libraries or font downloads.

## Before sharing

- Add only project details and examples you can describe accurately.
- Add education or experience details only if you want to share them.
- Review the resume and contact pages before adding personal information.
- Review all pages in a browser at phone and desktop sizes.

This project has not been published or pushed to GitHub.
